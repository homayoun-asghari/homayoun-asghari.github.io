# homayoun.me, second copy

An exact copy of [homayoun.me](https://homayoun.me), served free by GitHub Pages at
https://homayoun-asghari.github.io.

Once a day `mirror.py` downloads the live site and publishes it here. If the
site is down or no longer looks like itself, the copy is left as it was, so it
always holds the last good version.
